Users

📅 Published June 2025 📂 Platform: Keytelemetrics 👤 Audience: Administrators

Users access the platform and — depending on the features enabled on the client and the roles assigned to them — can view and manage items. Users can be created at Vendor level (accessing all clients) or at Client level (accessing only their specific client).

1. User Creation Methods

There are two ways to create a user on the platform:

MethodHow It WorksRecommended?
INVITE User receives an activation email with a link to set their own password Yes — preferred
AUTO Password auto-generated by the platform. User resets via Forgot? link or admin resets their account Use if no custom domain
Important: The invite method requires a Custom Domain to be configured at Vendor level. Without this the activation link will not generate correctly.

2. Creating a User

Navigate to Administration → Accounts → Users, click the + button, and complete the User Wizard:

FieldDescription
NameFull name of the user
Email AddressUsed for login and alert notifications
Mobile NumberUsed for SMS alert notifications
Cost CentreAssigns the user to a Cost Centre, controlling which assets they can see
Time ZoneEnsures trip and alert times display correctly for the user's location
LanguagePlatform display language for this user
Send InviteWhen checked, sends an activation email. Uncheck to auto-generate a password instead

Selecting a Role

After completing personal details, click Next to select the user's Role. If no custom roles have been created, only Administrator will appear:

Completed User

Once finished, the user appears in the list with all their details visible in the information panel. This can be edited at any time:

3. Resetting a User's Account

If a user has forgotten their password and cannot use the login screen to reset it, an administrator can reset their account. This suspends the account and sends the user an email with a link to create a new password.

Select the user, click the Reset button, then click OK to confirm:

Note: This reset option also works for accounts where a password was auto-generated during creation and the user never set their own.

4. Configuring User Notifications

To receive alert notifications, edit the Notifications section on the user's profile. Configure when SMS can be sent and which notification method to use per alert priority:

SettingDescription
Allow SMS From / ToTime window during which SMS notifications can be sent to this user
Low PriorityNotification method: None, Email, SMS, or Email & SMS
Medium PriorityNotification method: None, Email, SMS, or Email & SMS
High PriorityNotification method: None, Email, SMS, or Email & SMS
Prerequisite: An Email Server and/or SMS Gateway must be configured at vendor level before email or SMS notifications will work.
